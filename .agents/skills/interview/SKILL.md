# interview

## 목적
담당자 DM 인터뷰 시간을 15분 이내로 줄인다. README에 있는 정보는 사용자가 묻지 않게 하고,
README에 없는 것(우선순위·숫자·경계)만 질문 목록으로 남긴다.

## 절차
1. `README.md`와 작업 공간의 데이터·문서 파일을 읽는다. 코드는 건드리지 않는다.
   `SCENARIOS.md`의 표를 보고 문제 유형(A~G)을 고르고 근거를 한 줄 적는다. 섞여 있으면 후보 2개를 적는다.
2. `INTERVIEW.md`의 "README에서 이미 확인된 것" 섹션과, Q1~Q6 중 README로 답할 수 있는 빈칸을 채운다. 출처를 `(README §x)`로 표시한다.
3. 채우지 못한 질문만 골라, 사용자가 DM에 그대로 붙여 넣을 수 있는 **질문 문장 3~5개**를 우선순위 순으로 출력한다. Q1(우선순위)·Q3(정량화)·Q5(경계)는 README에 답이 있어도 확인 질문으로 포함한다. Q3는 고른 유형의 문장만 쓴다.
4. 데이터 파일이 있으면 스키마(컬럼명, 행 수, 결측, 날짜 범위)를 3줄로 요약해 "데이터 원천" 칸에 넣는다.

## 출력
- 수정된 `INTERVIEW.md`
- 터미널에 "DM에 보낼 질문" 목록

## 하지 않을 것
- 해법·기능 제안. 이 단계는 문제 파악만.
- 담당자 답변을 추측해서 채우기. 모르는 칸은 비워 둔다.
